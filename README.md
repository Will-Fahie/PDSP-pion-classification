To train models:
Download the "extracted-data" folder from https://drive.google.com/drive/folders/1HkrVxaCykFLPgSDN6D5iAfxyU0l9aMr2?usp=drive_link and drop it into the project root.
Then run data-preparation.ipynb to generate the train/test data.

Ordinarily you would need to run the classifier notebooks before model comparison and topology selection, but I have left my results in there so they should work immediately.
